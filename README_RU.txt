# Fox Spirits AR v12 — Animation patch

Это обновление ТОЛЬКО анимаций; персонажи и текстуры не меняются.

## Загрузка на GitHub Pages

В репозитории ElJitto/AR-Project замените файлы `index.html`, `preview.html`, `magic.js` и добавьте `preview_v12.html` в корень ветки `main`. Остальные файлы (girl.glb, white_fox.glb, black_fox.glb, targets.mind, card.png, ar.js, preview.js) НЕ нужно изменять.

Для проверки откройте https://eljitto.github.io/AR-Project/preview_v12.html (после успешной сборки GitHub Pages).

## Что анимировано

- Девушка: плавное дыхание/покачивание всего персонажа.
- Лисята: лёгкое подпрыгивание и наклоны корпуса; осторожный процедурный изгиб хвостового веера в шейдере.
- Сакура: падающие и вращающиеся лепестки.

**Предел:** все GLB статические (нет костей/анимационных клипов). Каждая лапа, ухо, хвост и руки девушки пока не двигаются независимо; для объятий и отдельного управления хвостами нужен риггинг.

Проект собран на основе v11. Проверены пути, HTML и синтаксис JS, но фактическую плавность и рендеринг на конкретном телефоне нужно испытать после публикации. Если шейдер вызывает визуальные дефекты, удалите атрибут `fox-tail-wave` у двух `a-gltf-model` в `index.html`/`preview.html`.
