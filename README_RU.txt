FOX AR V9 — исправление «летающей головы» и масштаба

В предыдущем girl.glb тело было случайно отключено от структуры сцены GLB: присутствовала только видимая накладка лица.
Версия v9 заново привязывает тело, сохраняет исправленное лицо и использует фиксированные размеры.

Замените в корне GitHub репозитория три файла:
  girl.glb
  preview.html
  index.html

Остальные файлы (black_fox.glb, white_fox.glb, magic.js, ar.js, preview.js, targets.mind) НЕ ТРОГАЙТЕ.

Дополнительно можете загрузить preview_v9.html и открыть https://eljitto.github.io/AR-Project/preview_v9.html

Все 3D-файла GLB не анимированы скелетом; лёгкое покачивание выполняется на странице.
В браузере через телефон проект не протестирован; сначала проверьте v9 и пришлите скриншот.
