FOX SPIRITS AR v27 — ИСПАНСКИЙ + КРАСИВАЯ ЗАГРУЗКА

Изменены только оформление загрузки и язык интерфейса.
Испанский по умолчанию. Кнопка ES / RU позволяет проверить русский.
Показывается число загруженных 3D-моделей: 0, 1, 2 или 3 (не фальшивые проценты).
Во время загрузки можно открыть обычный 3D-просмотр без камеры.
В AR экран скрывается только после загрузки всех трёх моделей и запуска камеры.

ШАГ 1. Загрузить в корень репозитория ElJitto/AR-Project:
  magic_v27.js
  fox_ui_v27.css
  fox_ui_v27.js
  ar_v27.html
  preview_v27.html

Существующие 3D-модели и другие файлы не изменяй.

ШАГ 2. Проверить на телефоне:
 https://eljitto.github.io/AR-Project/preview_v27.html
 https://eljitto.github.io/AR-Project/ar_v27.html

Проверить: плавная загрузка, работа ES/RU, полуприсед/поглаживание/прыжок, возврат камеры после потери маркера.
После успешного теста загрузить также index.html и preview.html (с заменой) для основной ссылки QR.

Если CDN A-Frame/MindAR недоступны, страница не сможет запустить AR.
Это не заменяет тест на iPhone Safari и проверку качества сети.
