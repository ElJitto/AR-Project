Нажми на кнопку «🐾 Погладить».
Девушка задерживается в позе у лисят и делает небольшие движения локтями; лисята нежно покачиваются под руками.
Клип Pet создаётся в браузере из имеющегося Cuddle/Greet — скелет и файл GLB не меняются.
Честное ограничение: в модели девушки нет костей кистей, поэтому анимация поглаживания пока условная, без точной постановки ладоней на головах.

Сайт GitHub Pages может оставаться недоступным для v20 до завершения зависших публикаций. Файлы проекта сохраняются в репозитории независимо от статуса публикации.
