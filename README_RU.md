# Fox Spirits AR — v7: первые движения без скелета

Этот архив содержит **те же три настоящих GLB**, включая исправленное лицо девушки, плюс новые эффекты движения хвостов и лепестки сакуры. Никаких платных подписок не требуется.

## Что реально анимировано
- Лёгкое покачивание всей девушки (вдох/выдох и поворот на 1°).
- Два лисёнка плавно движутся вверх и вниз.
- **Экспериментальное движение задней части хвостового веера** в виде мягкой GPU-деформации — отдельные хвосты пока не имеют костей, поэтому они не могут двигаться независимо.
- Лепестки сакуры кружатся вокруг персонажей.

**Не сделано:** девушка не гладит лисят руками, глаза не моргают, уши и все девять хвостов не анимированы по отдельности. Для этого необходим риг / скелет и монтаж анимаций в Blender. Не выдавайте эту сцену за готовую скелетную анимацию.

## Как проверить на телефоне (без AR)

1. Распакуйте ZIP. Загрузите **содержимое** в корень своего репозитория GitHub Pages, **сохраняя папку `models/`**.
2. Если в репозитории уже есть `targets.mind`, не удаляйте его — он нужен для AR. Иначе создайте его через https://hiukim.github.io/mind-ar-js-doc/tools/compile/ из **`card.png`**.
3. После публикации откройте адрес `https://ИМЯ.github.io/РЕПОЗИТОРИЙ/preview.html`.
4. Вращайте сцену пальцем, наблюдайте движения хвостов и лепестки.
5. Откройте главную страницу сайта, разрешите камеру и наведите на настоящую карточку.

## Новые файлы

- `magic.js` — лёгкая процедурная анимация хвостов на GPU, лепестки сакуры.
- `preview.html` и `index.html` — подключают эти эффекты.
- `models/*.glb` — те же исходные модели без изменений; можно заменить их на анимированные в будущем.

## Следующий шаг: настоящая скелетная анимация

1. Blender: File → Import → glTF 2.0, импортируйте `girl.glb`, затем отдельно оба fox GLB.
2. Для девушки создайте Armature, кости позвоночника, головы, плеч и рук, привяжите тело к скелету (Automatic Weights), проверьте весовые группы. Лицевую накладку и очки лучше привязать к кости головы.
3. Для одного лисёнка создайте кости тела, головы и **по цепочке 2–3 кости на каждый хвост**. Назначьте веса, плавно меняя угол хвостов в разные моменты.
4. Сделайте цикл 4–6 секунд: покачивание, движение хвостов, повороты головы. Переключите в NLA/Action и экспортируйте `.glb` с `Animations` и `Skinning`.
5. В сцене используйте `animation-mixer` из aframe-extras для воспроизведения анимации внутри GLB. Уберите `fox-tail-wave`, когда заработает скелет хвостов, чтобы деформации не мешали друг другу.

## Требования и ограничения

- `targets.mind` отсутствует — файл надо создать из `card.png` для настоящего AR.
- Веб-страница должна открываться через HTTPS, а не как локальный файл.
- Процедурный эффект хвостов — первая экспериментальная версия; проверьте на своём телефоне. При проблемах снимите атрибут `fox-tail-wave` с обоих `<a-gltf-model>` в `index.html` и `preview.html`.
- Три GLB всё ещё довольно тяжёлые; при лаге сначала ограничьте количество лепестков, затем упростите геометрию.
