# Fox Spirits — первая AR-карточка

Это **рабочий по структуре стартовый WebAR-проект**, но **не финальные 3D-модели**. В демо девушка и два девятихвостых лисёнка собраны из простых объёмных фигур A-Frame, чтобы сначала проверить распознавание, положение моделей и анимацию. Качество и сходство с рисунком придут на следующем этапе после создания собственных .glb моделей.

## Что в архиве

- `card.png` — основное изображение карточки размером 63 × 88 мм, 300 DPI. **Именно из этого файла надо создавать `targets.mind`**.
- `print_A4_single_300dpi.png` — A4 с одной карточкой в реальном размере и метками резки.
- `print_A4_six_300dpi.png` — A4 с шестью карточками, если захочется напечатать сразу несколько.
- `index.html` — AR-страница.
- `app.js` — 3D-персонажи-заглушки, виляющие хвостами, девушка и эффекты.
- `make_cards.py` — скрипт сборки принтов (нужен только для изменения дизайна).
- **`targets.mind` нужно добавить самостоятельно**: см. ниже. Без него камера не сможет распознать именно эту карточку.

## Шаг 1. Распечатать карточку

Открой `print_A4_single_300dpi.png` или `print_A4_six_300dpi.png` и при печати выбери **масштаб 100% / Actual size**. Не включай опцию «по размеру страницы» (Fit to page) — она изменит размер карточки. Используй матовую или полуглянцевую фотобумагу, если можешь: зеркальные блики ухудшают распознавание.

Итоговый размер каждой карточки **63 × 88 мм**. Метки резки показаны снаружи контура карточки. Если печатать не на A4, можно просто использовать `card.png` с выставленным физическим размером 63 × 88 мм.

## Шаг 2. Превратить рисунок в маркер MindAR

1. Открой в браузере [официальный компилятор MindAR](https://hiukim.github.io/mind-ar-js-doc/tools/compile/).
2. Загрузи **`card.png`**, не скриншот и не A4-лист.
3. Нажми **Start**, затем **Download**.
4. Сохранённый файл должен называться **`targets.mind`**. Перенеси его в ту же папку, где `index.html`.

Компилятор находит отличительные детали рисунка, поэтому не нужно рисовать QR-код на карточке.

## Шаг 3. Опубликовать сайт с HTTPS

1. Создай новый **публичный GitHub-репозиторий** `fox-spirits-ar` (для первого бесплатного теста; можно позднее изменить хостинг).
2. Загрузи в корень репозитория `index.html`, `app.js`, `card.png`, `targets.mind` и `.nojekyll`.
3. В GitHub открой **Settings → Pages**; в **Build and deployment** выбери **Deploy from a branch → main → /(root)**, сохрани.
4. GitHub покажет адрес сайта вида `https://<имя-пользователя>.github.io/fox-spirits-ar/`.
5. Открой сайт на Android в Chrome. Нажми «Открыть AR-камеру», разреши камеру и наведи её на распечатанную карточку.

Без HTTPS камера обычно недоступна в обычном браузере. Открытие `index.html` напрямую с телефона, как локального файла, тоже не подходит.

> Если вы ещё не напечатали карточку, покажите `card.png` на другом экране и наведите камеру на экран. Это тест распознавания; для него нужен **второй экран или распечатка**.

## Шаг 4. Переходим от тестовых фигур к красивым персонажам

Следующая работа — получить **три настоящие 3D-модели** и анимации, сохранив стиль рисунка: девушка с тёмными волосами, очками, красно-белым верхом и чёрной юбкой; белый девятихвостый лисёнок с красными отметинами; чёрный девятихвостый лисёнок с красными отметинами.

Для этого подходят Blender и программы для создания 3D-моделей по референсам. Готовые `.glb` загрузим в проект, заменив процедурные 3D-фигуры, и запустим idle-анимации. **Обычной PNG-иллюстрации для красивой поворачивающейся 3D-модели недостаточно**; GIF или видео тоже не заменяет трёхмерную геометрию.

## Если что-то не работает

- Чёрный экран или ошибка камеры: проверить Chrome, разрешение камеры и HTTPS.
- «Ничего не появляется»: проверить `targets.mind` в той же папке, реальную распечатку, достаточно света и отсутствие бликов.
- Если рисунок меняется, нужно заново скомпилировать `targets.mind` из новой версии `card.png`.
- Если физическая карточка распечатана сильно меньше 63 × 88 мм, распознавание может стать менее устойчивым.

Проверенные официальные материалы: https://hiukim.github.io/mind-ar-js-doc/quick-start/compile/ и https://hiukim.github.io/mind-ar-js-doc/examples/basic/
