Fox Spirits AR v8 HOTFIX

1. Загрузите содержимое этой папки (index.html, preview.html, preview_v8.html) в корень репозитория ElJitto/AR-Project через GitHub Add file -> Upload files. Подтвердите замену двух существующих файлов.
2. Подождите, пока GitHub Pages опубликует новый коммит (Actions).
3. Откройте https://eljitto.github.io/AR-Project/preview_v8.html
4. На экране появится счётчик "3D-модели: 0 / 3"; если загрузка не удастся, увидите имя проблемной модели.

В v8 модели загружаются напрямую из корня репозитория, без блокирующего a-assets. Встроен автоматический пересчёт масштаба моделей по фактической геометрии. Экспериментальная деформация хвостов отключена временно, чтобы исключить ошибки шейдеров. Модели GLB и targets.mind менять не требуется.

Важно: браузерная проверка на вашем телефоне ещё необходима.
